# Decisions

- **GEI-A001** — Build as a dependency-free static analytical product backed by a reproducible Python pipeline.
- **GEI-A002** — Ingest broad source data before deriving the Top-50 universe.
- **GEI-A003** — Keep raw, modeled, and displayed values distinct; Phase 1 never interpolates.
- **GEI-A004** — Latest-value rankings always display observation year.
- **GEI-A005** — Defer composite scores and forecasts until source and metric governance are approved.
